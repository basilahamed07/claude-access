# Dataset sources

| File | Rows | Source | Licence |
|---|---|---|---|
| `attacks.jsonl`, `clean.jsonl` | see `eval/README.md` | Written by hand for this repository by the project's authors, plus mechanical transformations of those texts (zero-width, base64, HTML comment, CSS-hidden, homoglyph, email/HTML wrappers) generated by `build_datasets.py` | Apache-2.0 |

No third-party or public dataset is included. Public sets (for example prompt-injection benchmarks on Hugging Face) could not be
downloaded in the environment this was built in. If you add some, record each source, its licence and the rows taken from it here
and keep `licence` filled in on every row (the loader rejects rows without it).

## Review
The hand-written items have not been independently reviewed. Before relying on the numbers, review a random 20 % sample of
`attacks.jsonl` and `clean.jsonl` for label errors and for texts that are too easy.
